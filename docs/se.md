# 効果音（SE）

`npm run se`（= `python scripts/se/build.py [id ...]`）で `scripts/se/` の合成コードから作り直す．
出力は `public/audio/se/<id>.mp3`（48 kHz・192 kbps・ステレオ）と `manifest.json`（`id, file, duration, peakDb`）．
中間物（wav・スペクトログラム `spec_<id>.png`・計測表 `report.json`）は `build-audio/se/` に出る．
外部の音源は使わず，すべて numpy / scipy で合成している．

## 共通の作り

- **音量はファイル側で決める**．各 SE に目標 true peak（4 倍オーバーサンプリングで測る）を持たせ，mp3 にしてから
  デコードし直して測り，目標を超えない範囲で寄せる．大きい系（kyuin・gekiatsu・button_press・cutin_gold・gimmick・freeze）は
  -1 dBTP，小さい系（launch・nail・miss・count_tick）は -20〜-26 dBTP．再生側はゲイン 1 のまま鳴らす．
- **先頭に無音を置かない**．合成後に先頭の完全な無音を落とし，末尾は -60 dB 以下を切って 20 ms でフェードする．
  LAME ヘッダの遅延情報を読むデコーダ（ffmpeg で確認）での先頭の遅れは全 SE で 0.4 ms 以下．
- **層を重ねる**: アタック（帯域ノイズのクリック）・本体（発振器／FM／モード合成）・低い芯（ピッチが落ちるサイン．
  小型スピーカーでも聞こえるよう tanh で倍音を足す）・煌めき（ランダムな高音のピン）・残響（合成 IR の畳み込み．高域ほど早く減衰）．
- 乱数の種は id から決まるので，何度作っても同じ音になる．

## 各 SE の層

| id | 層 |
|----|----|
| launch | バネのクリック + 高域ノイズの短い吹き + 小さな金属モード 2 本（約 60 ms） |
| nail1..4 | 2.7〜4.6 kHz を基音にした金属モード 3〜5 本（15〜45 ms で減衰）+ 超高域のクリック．4 種で基音と本数を変える |
| heso_in | FM ベルの上行 2 音（E6→B6）+ 2 倍音 + 短い残響 |
| payout | 玉の金属粒（モード 3 本）を密度の山に沿って約 100 粒散らす + 37 Hz で揺れる低いガラガラ |
| attacker_in | C7 の明るい FM ベル + 1 オクターブ上 + 高域クリック |
| hold_white / blue / green | ベル 1 音 / 2 音 / 3 音（緑は煌めき付き）．色が上がるほど残響を長く |
| hold_red | 低い芯（160→55 Hz）+ 歪ませた鋸波のブラス + ベル 4 音の分散和音 |
| hold_rainbow | 重低音（140→38 Hz）と歪んだ芯 + 600→3200 Hz を 0.35 s で上がる FM の束 + ベル 5 音 + 前半に密な煌めき + 1.8 s の残響 |
| hold_change | 800→2600 Hz を 0.14 s で上がる矩形 + 鋸波 + 2 倍音（キュインの縮小版）+ 煌めき + 小さな衝撃 |
| reel_stop / reel_stop_center | ノイズのクリック + 樹脂のモード．center は低い芯・もう 1 組のモード・短い残響で重く |
| reach | ピッチが落ちる低音 + 55 Hz のデチューン鋸波（フィルタが閉じる「ドゥーン」）+ 180→1600 Hz の上昇鋸波とノイズ（フィルタが開く） |
| cutin_blue / red / gold | 2 本の風切り（0.16〜0.22 s で帯域が上がるノイズ）→ 衝撃（ピッチが落ちる低音・クリック・歪んだスナップ）．red は歪んだ低い鋸波を追加．gold はさらに金属の和音・上昇する鋸波・煌めきの尾・2.2 s の残響 |
| button_appear | トレモロが 8→32 Hz に加速する上昇音（160→1500 Hz）+ 吸い込むノイズ + 最後に高いピン |
| button_press | 170→42 Hz に急降下するサイン + 歪ませた 220 Hz / 260 Hz の芯（倍音担当）+ 低いノイズの胴 + クリック + 短い部屋鳴り |
| gekiatsu | 110→30 Hz の爆発的な低音 + 歪んだ低域ノイズの胴 + ゴング（非整数次の倍音 18 本，左右で僅かに音程差）+ 高いベル + クラッシュ + 3 s の残響 |
| kyuin | 520→3100 Hz を 0.28 s で鋭く上がり 3350 Hz まで伸びる．主音（矩形と鋸波のユニゾン）+ 1 オクターブ上のサイン + 5 度上の FM + 1 オクターブ下の三角波 + 音程を追う帯域ノイズの息．28 Hz のトレモロとビブラート．頭に低い衝撃，上がり切った所から煌めき，1.4 s の残響（全長約 2.2 s） |
| freeze | 「ブツッ」という切断音 → 約 0.4 s の無音 → 45→300 Hz に上がる歪んだ鋸波の束（共振フィルタが開く）+ ピンクノイズ + 重低音 + 長い残響．先頭を無音にしないため切断音から始める |
| miss | 130→85 Hz に下がる矩形波を低域通過 + 柔らかいノイズ（小さめ） |
| gimmick | 短い風切り → 金属の板 4 枚の衝突 + クラッシュ + 低い衝撃 + 破片のカラカラ + 残響 |
| round_start | C6-E6-G6-C7 の上行チャイム → 同じ 4 音の和音で伸ばす + 煌めき |
| denchu_open | 機械のクリック 2 つ（約 45 ms 間隔）+ 小さなモード + 高域ノイズ |
| count_tick | 6 kHz 付近の極短いクリック（約 12 ms） |
| flash | 上へ掃くハイパスのノイズ + 刃の高いリング（左右で僅かに音程差）+ 煌めき + 残響 |
